# Goowac Client

Goowac Client is a Fabric client project for Minecraft Java 1.21.11.

The repository contains the complete source in `goowac-client-source.tar.gz`. The archive includes the Gradle project, Fabric metadata, the Goowac GUI/module registry, and the macOS Spotify now-playing/lyrics integration.

The project deliberately does not implement anti-cheat bypasses, detection evasion, or server-exploit automation.

Builds are handled by GitHub Actions. A successful push to `main` builds the JAR and creates/updates the corresponding GitHub release.
